# 根音与和弦性质：文献和研究问题

2026-11-13 的调研与候选方案记录。后续已将主问题收窄到附加七音与三音强度；当前目标及实验顺序见[项目 README](../../../README.md)。以下保留当时的建议与证据。全文与关键章节审读记录见 [literature_audit.md](literature_audit.md)。商业资料只代表其发布时披露的做法。

最适合继续研究的问题是：**在轻量和弦识别中，根音变化和同根音的大、小调变化，是否需要不同的时间约束？** 当前结果提供了动机，但还没有建立这种区分会带来收益。

## 领域已有做法

档案来源补注：频谱表示、和弦模型和时间解码的流程背景见 [McVicar 2014](https://doi.org/10.1109/TASLP.2013.2294580)、[Pauwels 2019](https://archives.ismir.net/ismir2019/paper/000004.pdf)、[Müller 2021，§4.5](https://doi.org/10.3390/signals2020018)；阅读范围见[来源审读](../research_questions_2026-11-15/source_audit.md)。下表各方法及近期结果仍以对应原始论文为依据。

| 路线 | 已有方法 | 对本项目的启示 |
| --- | --- | --- |
| 改善频谱表示 | Mauch–Dixon (2010) 在标准化频谱上用泛音字典和 NNLS，再构造普通及低音 chroma；Deep Chroma (2016) 从带上下文的频谱学习和弦相关音级。 | 音符估计、上下文和频谱预处理已有先例；当前基频投影的收益及其适用条件仍需要解释。 |
| 表示和弦组成 | ChordFormer 把根音与三和弦类型联合编码，另预测低音及扩展音；Poltronieri 等 (2025) 预测根音、低音和音级集合。 | 拆分预测已被研究，但不同组成的收益未必一致。 |
| 改善时间模型 | Korzeniowski–Widmer (2018, EUSIPCO) 区分和弦持续时间与进行模型，并检查声学分数、温度及标签平滑的交互。 | 同一个转移惩罚不一定对不同前端产生相同的平滑强度。 |
| 扩大数据覆盖 | Phan 等 (2026) 用教师模型给大量音频生成伪标签，再以人工标签和蒸馏继续训练。 | 能处理数据稀缺，但包含大规模预处理、教师推理和训练成本；不是当前小实验的必要前提。 |

[Poltronieri 等的 Table 2](https://arxiv.org/pdf/2509.01588v1) 给出一个直接相关的观察：Conformer 从固定词表改为分解输出后，Root 从 81.4 提至 83.4，MajMin 却从 77.5 降至 77.2；加入协和关系平滑后为 84.0 和 77.8。各指标并非总是一起改善。这是该实验的有限证据，没有证明与我们相同的错误机制。其 Root 与本项目排除 N 的根音指标不能直接比较数值。

Chordify 的 [2020 年说明](https://chordify.net/pages/algorithm-summer-bootcamp/) 介绍独立的和弦与节拍网络；[2021 年说明](https://chordify.net/pages/chordify-algorithm-learns/) 介绍用户及编辑纠错，并承认没有实际和弦的片段也可能被赋予和弦。这些资料未公开完整当前架构、误差分解或端到端成本。

## 保存的预测告诉了我们什么

重新对齐已有 fast-set 区间，没有重新推理或调参。投影的整体和弦准确率从 64.70% 提高到 67.80%，根音准确率从 73.91% 提高到 78.32%；下面检查改善中仍出现的性质错误。下表为“预测根音正确，但大、小调错误”的累计时长：

| 阶段 | Long STFT | Projection |
| --- | ---: | ---: |
| 逐帧识别 | 49.58 s | 49.64 s |
| Viterbi 后 | 19.07 s | 27.41 s |

这两个阶段的分组不同，不能仅由表格断言解码器导致了性质错误增加。为排除错误类别之间的迁移，进一步比较同一时间区间：

- 解码后，两种方法根音都正确的 679.28 秒中，性质错误从 19.03 增至 27.37 秒。
- 原本完整正确而被投影判为同根的另一种大小调和弦的区间为 10.60 秒；反向修正为 2.26 秒。根音错误与性质错误之间的两个迁移方向各约 0.046 秒。
- 净性质错误增加 8.34 秒，`rock_6` 单独增加 9.89 秒，其他录音有抵消。这不是遍布所有录音的现象。
- 逐帧比较中，同一批双方根音正确的区间上，两个方向为 7.59 和 7.54 秒，接近抵消。此时共同根音正确区间为 613.24 秒，与解码后子集不同。

上述结果将时间解码与声学表示的交互列为优先假说；不能据此认定投影丢失了三音。数值和录音级明细见 [paired_errors.json](paired_errors.json)。

## 建议的研究问题

**RQ1：区别根音变化与性质变化的时间约束，能否保留投影的根音收益，同时减少完整和弦错误？**

先在开发集比较三种逐步增加复杂度的方案：重新选择一个统一转移惩罚；分别设置根音变化与同根性质变化的惩罚；再视前两项证据决定是否让性质惩罚依赖可观测的三音（区分大、小调的音）证据。后者可能抑制短时误判，也可能延长一个错误初始标签，两个方向都要统计。

对同根的大、小调切换使用 λq，对任何根音变化使用 λr；λq=λr 时恢复统一惩罚。不要把两项直接相加而无意中对部分转移收取两次代价。保持 24 个和弦状态及原 N 规则。短的合成进行可分别改变三音强度、性质切换时刻及和弦时长，检查弱证据与长时错误的关系；真实录音用于检查这些规律是否适用。

完整和弦准确率是主指标，另报根音准确率、同区间的性质修正与损害、边界误差和完整处理时间。若统一惩罚重选已经解释收益、结果只在已看过的 `rock_6` 上成立，或性质错误的减少被新增根音错误抵消，就不支持新增结构。这里的贡献目标是解释适用条件和检验一个有针对性的改动；分开转移代价或置信度加权本身不作首创声明。

**RQ2：NNLS 相比独立投影的额外竞争，是否损失了区分大、小调的弱三音证据？**

在同一根音、同一时刻比较两种表示中的大、小三音差值，再用可控三音强度与谱形变化区分证据损失和字典失配。当前等权三和弦模板在固定根音下，大小调得分差本来就是 `(x[r+4] − x[r+3]) / sqrt(3)`，因此仅把同一打分重写成“先根音、后性质”不会自动产生新方法。必须改变实际使用的声学证据或时间处理。

另一个必要对照是频谱标准化与字典的交互：原 NNLS 文献采用标准化的对数频谱，而我们的简化版本采用线性频率的 Hann 幅度谱。不能把泛音字典在本项目退步解释成泛音信息无用。RQ2 的频谱检查可作为 RQ1 的配套分析；是否扩展成独立课题取决于开发数据中的证据。

## 范围与安排

第一轮约 2–3 天：开发集错误转移、分数差与统一平滑对照。第二轮约 2–3 天：一个结构化时间模型及可控样例。新曲目的确认实验取决于取得合法、对齐的音频与标注，下载和对齐时间不能省略。

fast、slow 和原 GuitarSet 测试集都已被查看，可用于诊断；新方法的确认应使用未参与设计的曲目。同曲目的速度、演奏及通道版本应同组处理。fast 集主指标覆盖 59 段，根音指标覆盖 58 段，参考覆盖率 59.56%；这也限定了当前观察能解释的内容。

研究过程使用 creative-thinking-for-research 的问题重述与隐含约束检查：从“提高根音分数”转向“解释完整和弦错误”，检查“各组成共用同一时间约束”和“频谱残差更小就应分类更好”这两个假设。独立讨论者根据实际提供的摘录提出反例；由于子代理工具不可用，原文获取、代码检查和数值重算由主代理完成。
