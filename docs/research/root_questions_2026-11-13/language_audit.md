# 一、整体观察

审阅范围：本目录 README.md、literature_audit.md 的完整拟稿，以及 paired_errors.py 的说明文字。使用 academic-language-audit 和 nature-writing；按研究笔记的相关工作、实验解释与讨论处理，保留中文说明和英文文献核对，不套用投稿口吻。Nature 写作原则用于先给出问题、再给证据和可区分的解释；不把实验记录全部塞进主论述。

定位采用文件名、章节和原句，不使用虚构页码。六篇论文的实际阅读范围见 literature_audit.md；商业资料仅限所列两篇历史说明。主要需修正的是：局部性质错误与整体准确率的关系、两种收益不能“抵消”的措辞，以及阅读深度的表述。

# 三、综合建议

先区分整体改善和局部错误，再提出时间约束假说。保留统一惩罚重新调优这一强对照；现有观察不能证明新的分量约束有效。六篇文献按输入、操作、任务、误差与保证、总成本和失败条件记录，不把论文未报的运行时间写成效率优势。

上述修改已用于本目录最终文本。逐段交叉统计的行、列汇总与原保存指标在 1e-7 秒容差内一致；记录在 validation.json。新方法收益、三音证据损失、跨曲目推广均待实验，不在本次审查中补造结果。
