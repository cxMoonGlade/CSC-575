# Project resources

## Data

The project will use Beatles recordings held locally with [Isophonics chord annotations](https://isophonics.net/content/reference-annotations-beatles). Recording versions and annotation timing will be checked before evaluation.

Other resources collected for background and possible later experiments:

- [Chordify CASD](https://github.com/chordify/CASD): multiple expert chord annotations.
- [ChoCo](https://github.com/smashub/choco): a collection of harmony annotations in JAMS format.
- [Jazz Audio Aligned Harmony Dataset](https://github.com/MTG/JAAH): jazz harmony annotations and chroma features.

Recordings and downloaded resource archives are kept locally.

## Software and examples

- [librosa chroma example](https://librosa.org/doc/0.11.0/auto_examples/plot_chroma.html): a starting point for feature extraction and plots.
- [mir_eval](https://github.com/mir-evaluation/mir_eval): music information retrieval evaluation routines.
- [Pitch Class CNN](https://github.com/christofw/pitchclass_cnn): reference implementation for learned pitch-class features.
- [Chord recognition system](https://github.com/krist311/chords-recognition): another implementation for background reading.
